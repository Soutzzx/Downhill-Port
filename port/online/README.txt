Downhill Domination online (PC port) - races for 2 to 4 players over the internet
==================================================================================

What you need
- Windows 10 or 11 and a controller (Xbox-style, DualSense or DualShock 4; the keyboard works too:
  arrows, X = Cross, C = Circle, Z = Square, Enter = START).
- Your own copy of Downhill Domination for PS2, USA version (SCUS-97177), as an .iso disc image.
  Other versions and modified images are refused: every PC must run exactly the same game.
  This package contains no game data and no PS2 BIOS (none is needed).
- The address of a race server (online/server in the source is the server; anyone can run one).

Play
1. Unzip this folder anywhere and double-click Play-online.cmd.
2. Type your name, paste the server address into "Server" (only the first time: it is kept in
   dhd.ini in this folder), choose your ISO (the first check takes about half a minute) and
   your rider.
3. To create a race: pick a track and when to start, press Start, and send the 6-character
   code to your friends. To join: choose "Join with a code", type the code, press Start.
4. Every game goes through the menus by itself and waits in the room. The race starts when
   everyone is in (or when the host presses START or Enter in the game window, if chosen).
   Everyone's countdown starts together.
5. Resolution, display and widescreen are your own choice; they don't have to match your
   friends'. Settings.cmd has the rest of the picture and sound options.

While racing
- Square attacks to the left, Circle to the right; hits on other players count on their screen
  too.
- The window title shows the room, your player number and the ping.
- If someone leaves, the host's PC takes over their rider and the race goes on.
- When you finish, the end of the race waits for the others (at most a minute and a half after
  the first finish), then everyone gets the same results.

Files
- dhd.exe: the game.  Play-online.cmd, Online.ps1: the online launcher.
- Settings.cmd, Launcher.ps1: all the PC settings (and a single-player start).
- dhd.ini: your settings, including the server address.
- online.log: the game's messages from the last session; send it along if something goes wrong.
